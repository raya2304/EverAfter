# EverAfter – Wedding Planning Website

EverAfter is a modern and responsive wedding planning website designed to help couples organize their special day in one place. The website provides an elegant interface for exploring wedding venues, services, vendors, photography inspiration, honeymoon destinations, and useful wedding planning resources.

The project combines a luxury wedding-inspired design with interactive features built using JavaScript. Users can calculate their wedding budget, manage a wedding checklist, view a countdown to the wedding day, filter the photo gallery, explore services and venues, and submit wedding enquiries.

## Features

* Responsive and modern wedding-themed design
* Beautiful hero section with wedding imagery
* Wedding services section
* Wedding venue listings
* Wedding inspiration gallery
* Gallery category filtering
* Wedding countdown timer
* Interactive wedding budget calculator
* Wedding checklist with add and remove functionality
* Wedding vendor section
* Honeymoon destination section
* Wedding tips and inspiration
* Contact and enquiry form
* Responsive mobile navigation
* Hover effects and interactive UI elements

## Technologies Used

* HTML5

## Main Sections

### Home

Introduces EverAfter with a beautiful hero section and calls-to-action for starting the wedding planning process.

### Services

Displays important wedding services including:

* Wedding Venues
* Decorations
* Photography
* Bridal Makeup
* Catering
* Entertainment

### Wedding Venues

Users can explore different wedding venues with location, ratings, descriptions, and starting prices.

### Gallery

A wedding inspiration gallery with category filters for:

* Ceremony
* Decoration
* Bridal
* Reception

### Wedding Countdown

Displays a real-time countdown showing the remaining days, hours, minutes, and seconds until the wedding date.

### Budget Planner

Allows users to enter their total wedding budget and estimated expenses for different categories. JavaScript calculates the total spending and remaining budget.

### Wedding Checklist

Users can add wedding tasks and remove completed or unnecessary tasks to help organize their wedding preparation.

### Vendors

Displays sample wedding professionals such as photographers, decorators, and bridal makeup artists.

### Honeymoon Destinations

Provides destination inspiration including Maldives, Bali, Paris, and Switzerland.

### Contact

A wedding enquiry form allows users to enter their details, wedding date, preferred service, and message.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the website and interact with the available features.

No backend or installation is required.
